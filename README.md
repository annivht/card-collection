
# Pokémon Card Collection

Selainohjelmoinnin harjoitustyö. Sovelluksella voi hallita Pokemon-korttikokoelmaa. Kortteja voi lisätä, hakea ja poistaa.

Frontend on toteutettu Reactilla ja backend Node.js:n Expressillä. HTTP-pyyntöihin käytetään Axiosia.

## Käynnistäminen

Backend:
cd backend
npm install
npm run dev


Frontend:
cd frontend
npm install
npm run dev


Sovellus avataan selaimessa osoitteessa http://localhost:5173.

Kortit tallennetaan palvelimen muistiin, joten muutokset eivät säily palvelimen uudelleenkäynnistyksen jälkeen.
